## 更新方法

`scripts/build_public_site.py` は、親ディレクトリにある解析成果から `docs/` の公開物を再生成します。

```bash
python3 scripts/build_public_site.py
```

GitHub Pages は `main` への push 後に Actions から自動デプロイされます。
